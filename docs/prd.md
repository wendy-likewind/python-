# 需求文档

## 1. 应用概述

### 1.1 应用名称

Wendy Wang 的个人主页

### 1.2 应用描述

展示 Wendy Wang 个人信息的网页应用，包含个人信息展示区和数字分身聊天区。用户可以浏览个人信息，并通过数字分身了解 Wendy 的职业、现状、兴趣以及精力管理、时间管理、户外爱好等话题。

## 2. 用户与使用场景

### 2.1 目标用户

- 想要了解 Wendy Wang 的访客
- 对 Wendy 的职业经历、兴趣爱好感兴趣的人
- 希望获取精力管理、时间管理、户外爱好相关建议的用户

### 2.2 核心使用场景

- 访客浏览个人主页，了解 Wendy 的基本信息
- 访客通过数字分身聊天，获取关于职业、现状、兴趣的信息
- 访客查看预设问题的回答，了解精力管理、时间管理、户外爱好等话题

## 3. 页面结构与功能说明

### 3.1 页面结构

```
个人主页
├── 个人信息展示区
└── 数字分身聊天区
```

### 3.2 个人信息展示区

#### 3.2.1 展示内容

- 头像
- 名字：Wendy Wang
- 一句话介绍：一个会风水学、八字命理的金融产品经理、创业者、户外爱好者和播客主
- 现状：学习股票投资和Vibe Coding
- 兴趣：创业、投资、FIRE、玄学、登山、潜水、钢管舞
- 特点：擅长整理模板和清单，擅长从零到一组织学习小组，擅长给身边的人带来正面的鼓励和建议，正在努力实现遗愿清单中的每一项内容

#### 3.2.2 设计要求

- 信息层次清晰
- 采用自然浅绿色、大海蓝色配色
- 高级、简约、清新、治愈风格
- 适配手机屏幕

### 3.3 数字分身聊天区

#### 3.3.1 功能说明

- 展示数字分身形象
- 提供聊天输入框
- 展示3个预设问题按钮
- 显示数字分身回答内容

#### 3.3.2 预设问题

1. 为什么能做这么多事？
2. 如何管理时间？
3. 为什么喜欢户外自虐？

#### 3.3.3 交互流程

- 用户点击预设问题按钮，数字分身显示对应回答
- 用户在输入框输入关于职业、现状、兴趣的问题，数字分身根据知识储备回答

## 4. 业务规则与逻辑

### 4.1 数字分身知识储备的

#### 4.1.1 基础信息

- 职业：产品经理
- 现状：学习股票投资和Vibe Coding
- 擅长：整理模板和清单，建立组织，领导力，关心和激励他人

#### 4.1.2 预设问答内容

**问题1：为什么能做这么多事？**
回答：其实我是一个精力很低的i人，但是我对于他人和世界怀有强烈的好奇心，这种求知欲支撑我不断探索新的事情

**问题2：如何管理时间？**
回答：我是一个重度的DDL fighter和拖延症患者，从心理上我会通过和他人一起合作的方式增加自己做事的动力，从行为上我会利用自己建立的时间管理涂色表管理时间，对于自己的长期计划每周固定时间形成习惯，减少在管理时间上的精力耗费

**问题3：为什么喜欢户外自虐？**
回答：我喜欢大自然，每当我在徒步很累的时候，或者是在海底呼吸的时候，我都不得不把精力集中在脚下的每一步和呼吸的感受，这让我获得“活在当下”的精神感受

### 4.2 数字分身回答规则

- 用户点击预设问题时，显示对应的预设回答
- 用户输入关于职业的问题时，回答「产品经理」相关内容
- 用户输入关于现状的问题时，回答「学习股票投资和Vibe Coding」相关内容
- 用户输入关于兴趣的问题时，回答「创业、投资、FIRE、玄学、登山、潜水、钢管舞」相关内容
- 用户输入关于擅长的问题时，回答「整理模板和清单，建立组织，领导力，关心和激励他人」相关内容

## 5. 异常与边界情况

| 场景                           | 处理方式                                                                                       |
| ------------------------------ | ---------------------------------------------------------------------------------------------- |
| 用户输入超出知识储备范围的问题 | 数字分身回复「这个问题超出了我的知识范围，请尝试询问关于职业、现状、兴趣或预设问题相关的内容」 |
| 用户输入空内容                 | 禁用发送按钮或提示「请输入问题」                                                               |
| 页面在不同尺寸手机上显示       | 自适应布局，确保信息完整展示                                                                   |

## 6. 验收标准

1. 打开个人主页，查看个人信息展示区是否完整显示头像、名字、一句话介绍、现状、兴趣、特点
2. 查看数字分身聊天区是否展示数字分身形象和3个预设问题按钮
3. 点击预设问题按钮「为什么能做这么多事？」，数字分身显示回答「好奇心旺盛，虽然精力低」
4. 在聊天输入框输入「你的职业是什么？」，数字分身回答包含「产品经理」相关内容
5. 在聊天输入框输入「你现在在做什么？」，数字分身回答包含「学习股票投资和Vibe Coding」相关内容
6. 在聊天输入框输入「你有什么兴趣爱好？」，数字分身回答包含「创业、投资、FIRE、玄学、登山、潜水、钢管舞」相关内容
7. 在手机上打开页面，确认页面布局适配手机屏幕，信息层次清晰
8. 确认页面配色为自然浅绿色、大海蓝色，整体风格高级、简约、清新、治愈
